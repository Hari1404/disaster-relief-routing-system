# ReliefNet - Phase 2B

This is the disaster-relief simulation engine.

## Build and Run Tests (Windows)

To build and run tests, execute the batch file:

```cmd
build_and_test.bat
```

## Build and Run Console (Windows)

To build the interactive console application:

```cmd
build_console.bat
```

Then run the application:

```cmd
relief_console.exe
```
